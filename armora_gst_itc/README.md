# Armora GST ITC

Odoo **18.0** module in the Armora GST Suite.

## Purpose

Input Tax Credit tracking and review for Odoo 20.

- Track ITC eligible, ineligible, and reversed amounts
- Support period review of purchase-side GST credit
- Foundation for ITC utilization and reconciliation extensions

## Dependencies

- `armora_gst_base`

## Status


Prompt 2 boundary: see [ARCHITECTURE.md](ARCHITECTURE.md).
Installable scaffold. Domain models, workflows, and tests are implemented in follow-up steps.

## Notes

Complements GSTR-2B / GSTR-3B modules. Does not auto-claim ITC on the GST portal.
