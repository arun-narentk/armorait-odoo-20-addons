# Hospital ERP

        Patients, appointments, and hospital operations foundation

        ## Business problem
        Clinics need an Odoo-native hospital core before adding billing, lab, and pharmacy modules.

        ## Solution
        Hospital ERP provides the ARMORA HMS foundation: patients, departments, appointments, and dashboard shell for healthcare workflows.

        ## Key benefits
        - Healthcare-ready data model
- Appointment scheduling base
- Department structure
- Extend with HMS packs
- Multi-company clinics
