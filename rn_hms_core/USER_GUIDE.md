# User Guide

        ## Hospital ERP

        Hospital ERP provides the ARMORA HMS foundation: patients, departments, appointments, and dashboard shell for healthcare workflows.

        ## Typical workflow
        1. Register patient
2. Book appointment
3. Assign department
4. Serve visit
5. Bill via extensions

        ## Tips
        - Start with demo data to learn the screens.
        - Configure settings before inviting end users.
        - Use dashboards for daily operations reviews.
