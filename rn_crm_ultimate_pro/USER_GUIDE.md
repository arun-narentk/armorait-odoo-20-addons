# User Guide

        ## CRM Enhancements

        CRM Enhancements adds scoring rules, duplicate detection, follow-up automation, and a CRM dashboard on top of Odoo CRM.

        ## Typical workflow
        1. Import leads
2. Score automatically
3. Detect duplicates
4. Schedule follow-up
5. Close won

        ## Tips
        - Start with demo data to learn the screens.
        - Configure settings before inviting end users.
        - Use dashboards for daily operations reviews.
