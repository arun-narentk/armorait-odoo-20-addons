# Armora GST Analytics

Odoo **18.0** module in the Armora GST Suite.

## Purpose

GST analytics and KPI views for Odoo 20.

- Period KPIs for outward/inward GST tax
- Exception and compliance trend summaries
- Read-only analytical views for management review

## Dependencies

- `armora_gst_base`

## Status

Installable scaffold. Domain models, workflows, and tests are implemented in follow-up steps.

## Notes

Analytics layer only. Does not modify accounting entries.
