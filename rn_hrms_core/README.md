# HRMS Core

        Employee lifecycle, org structure, and HR operations base

        ## Business problem
        Growing companies outgrow basic HR before they can deploy full payroll and talent suites.

        ## Solution
        HRMS Core extends Odoo HR with ARMORA employee lifecycle, org units, document hooks, and an HR overview dashboard.

        ## Key benefits
        - Structured employee records
- Org hierarchy
- HR dashboard shell
- Suite-ready architecture
- Community compatible
