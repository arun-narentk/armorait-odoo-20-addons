# Marriage Hall Management Core

Vertical ERP foundation for marriage halls, banquet centers, convention halls, and rentable event venues on Odoo 20 Community.

## Business problem

Marriage halls struggle with double bookings, poor advance tracking, manual billing, and disconnected spreadsheets. Few products cover booking, operations, and accounting in one Odoo-native platform.

## Phase 1 (this module)

- Venue / property master with configurable venue type
- Multiple halls with capacity, AC, parking, dining, kitchen, and stage
- Booking management with muhurtham, reception, engagement, and corporate events
- Calendar views and conflict detection
- Tentative, waitlist, and confirmed workflow
- Operations dashboard
- SaaS subscription tracking

## Shared platform with Temple ERP

Temple trusts often run marriage halls and guest houses. Booking, CRM, payments, inventory, and portal modules can be shared across `rn_temple_*` and `rn_hall_*` product lines.

## Installation

1. Add `rn_hall_base` to your addons path.
2. Install **Marriage Hall Management Core** from Apps.
3. Open **Marriage Hall > Configuration > Hall Settings**.
4. Create venue and hall records, then start booking.
