# Construction ERP Core

ARMORA IT Technologies construction platform for Odoo 20 Community.

Targets contractors, builders, and infrastructure firms that need project cost control, site operations, and procurement on one stack.

## Phase 1 features

- Construction projects, sites, phases, milestones
- BOQ with revisions and cost roll-up
- Cost estimation by material, labour, equipment, subcontract, overhead
- Site daily logs, issues, photos, AI summary hooks
- Material requests and purchase order workflow
- Labour attendance and contractor tracking
- Equipment registry and usage logs
- Running bills with retention and invoice hooks
- Management and site engineer OWL dashboards
- AI hooks: project Q&A, cost risk, material forecast (heuristic)

## Installation

1. Install Accounting, Purchase, Inventory, HR, Project.
2. Install **Construction ERP Core**.
3. Assign Site Engineer, Project Manager, or Construction Manager groups.

## Ecosystem

Works with AI Copilot, Workflow Builder, Invoice OCR, document platform, and WhatsApp when installed.
