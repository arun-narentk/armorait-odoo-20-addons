# Armora GST Purchase Reconciliation

Odoo **18.0** module in the Armora GST Suite.

## Purpose

Reconcile purchase invoices and GST ITC documents for Odoo 20.

- Match vendor bills to GST purchase documents
- Highlight missing, mismatched, or duplicate purchase GST data
- Accountant-friendly reconciliation status and differences

## Dependencies

- `armora_gst_base`

## Status


Prompt 2 boundary: see [ARCHITECTURE.md](ARCHITECTURE.md).
Installable scaffold. Domain models, workflows, and tests are implemented in follow-up steps.

Complements GSTR-2B workflows; does not replace armora_gst_2b_reconciliation.
