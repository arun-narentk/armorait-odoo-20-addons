# Installation Guide

## Requirements

- Odoo 20 Community
- Python 3.12
- PostgreSQL
- Dependencies: `base`, `mail`, `web`, `sale`, `purchase`, `account`, `crm`, `contacts`, `product`, `stock`

## Install from Apps

1. Update Apps list.
2. Search **Bookmarks**.
3. Click **Install**.

## Install from Git (Apps Store)

```text
ssh://git@github.com/arun-narentk/armorait-odoo-20-addons.git#20.0
```

Module technical name: `rn_bookmarks`

## Post-install

1. Assign **ARMORA Bookmarks / User** to users who need bookmarks.
2. Open **Settings > Bookmarks** and confirm hotkey and systray are enabled.
3. Optional: load demo data on staging to preview folders and tags.

## Upgrade

Upgrade the module from Apps after pulling the latest `20.0` branch. No manual SQL required.
