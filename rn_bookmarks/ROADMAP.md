# Roadmap

## Version 1.x (current)

- Universal record bookmarks
- List, menu, report, dashboard bookmark types
- Folders, pins, favorites, tags, notes
- Systray sidebar and Ctrl+B hotkey
- Create Bookmark wizard

## Version 2.0

- Team and shared bookmarks
- Shared folders with permissions
- Bookmark history timeline
- Smart pin suggestions based on open frequency
- Drag-and-drop folder moves in OWL sidebar

## Version 3.0

- AI bookmark recommendations
- Workspace sync with `rn_workspace` suite
- Cross-database bookmark export/import
- Executive bookmark dashboard with charts
