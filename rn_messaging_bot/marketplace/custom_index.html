Overview

Messaging Bot Engine for Odoo 20

Messaging Bot Engine Unified inbox and bot engine for customer messaging channels. It is built for Odoo 20 Community by ARMORA IT Technologies.

The Problem

  • Production status is tracked outside Odoo
  • Planners lack a single dashboard for open MOs
  • Quality and inventory signals arrive late
  • Related documents are hard to open from the order
  • Multi-company plants need consistent process

The Solution

  • Manufacturing ops views in Odoo
  • Smart navigation to related production docs
  • KPI dashboard for open and delayed work
  • Links to inventory and quality where used
  • Security for production roles

Installation

  1. Add rn_messaging_bot to your addons path
  2. Restart the Odoo service
  3. Apps → Update Apps List
  4. Search Messaging Bot Engine
  5. Click Install
  6. Complete settings and use the Moves smart workflows
