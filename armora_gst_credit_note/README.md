# Armora GST Credit Note

Odoo **18.0** module in the Armora GST Suite.

## Purpose

GST-aware credit note checks and workflows for Odoo 20.

- Validate credit note GST references and tax treatment
- Link credit notes to original invoices where required
- Surface GST completeness issues before posting/filing

## Dependencies

- `armora_gst_base`

## Status


Prompt 2 boundary: see [ARCHITECTURE.md](ARCHITECTURE.md).
Installable scaffold. Domain models, workflows, and tests are implemented in follow-up steps.

## Notes

Works with standard customer/vendor credit notes. Related: armora_invoice_credit_notes.
