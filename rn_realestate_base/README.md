# Real Estate ERP Core

Vertical ERP foundation for builders, property developers, and agencies on Odoo 20 Community. Goes beyond generic CRM with project hierarchy and unit inventory.

## Business problem

Real estate builders juggle leads in spreadsheets while unit inventory, bookings, payments, and construction progress live in separate tools. Standalone CRMs do not connect to Odoo accounting and project operations.

## Phase 1 (this module)

- Developer / builder master with RERA fields
- Projects, blocks/towers, and unit inventory
- Unit status: available, blocked, booked, sold
- Lead management with source, budget, and sales stage
- Sales dashboard with pipeline and inventory KPIs
- SaaS subscription tracking

## Differentiator vs generic CRM

This is positioned as **Real Estate ERP**, not lead-only CRM. Companion modules add booking, payments, agreements, commissions, construction progress, portal, and accounting on one Odoo stack.

## Installation

1. Add `rn_realestate_base` to your addons path.
2. Install **Real Estate ERP Core** from Apps.
3. Open **Real Estate > Configuration > Real Estate Settings**.
4. Create developer, project, units, and leads.
