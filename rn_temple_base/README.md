# Temple Management Core

Vertical ERP foundation for temples, trusts, ashrams, gurudwaras, churches, and other religious institutions on Odoo 20 Community.

## Business problem

Medium and large temples still run on paper registers, Excel, and disconnected software. Generic ERP products do not model devotees, donations, seva booking, festivals, annadhanam, and trust governance in one place.

## Phase 1 (this module)

- Temple / institution master with configurable institution type
- Multi-branch management
- Trustees and priests
- Departments
- Daily timings
- Festival calendar
- Operations dashboard
- SaaS subscription tracking

## Installation

1. Add `rn_temple_base` to your addons path.
2. Install **Temple Management Core** from Apps.
3. Open **Temple > Configuration > Temple Settings**.
4. Create your temple master record and branches.
