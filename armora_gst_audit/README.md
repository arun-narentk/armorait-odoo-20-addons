# Armora GST Audit

Odoo **18.0** module in the Armora GST Suite.

## Purpose

GST audit trail and review pack helpers for Odoo 20.

- Collect GST-relevant audit evidence for a period
- Summarize validation exceptions and configuration changes
- Support internal / external GST review workflows

## Dependencies

- `armora_gst_base`

## Status

Installable scaffold. Domain models, workflows, and tests are implemented in follow-up steps.
