# Temple Digital Platform

ARMORA IT Technologies temple platform for Odoo 20 Community.

Modern cloud platform for temples, trusts, mutts, and religious organizations across India and overseas.

## Phase 1 features

- Devotee profiles with family and donation history
- Donations: cash, UPI, card, bank, cheque, online with receipts
- Seva catalog and booking with slots, capacity, QR token
- Festival planning with sponsors and volunteer links
- Annadhanam: daily meals, sponsors, ingredient estimates
- Hundi collection with counting, verification, deposit audit
- Volunteer registry and asset tracking
- Trustee and office OWL dashboards
- AI hooks: seva Q&A, donation analytics, receipt search, event planning

## Positioning

Temple Digital Platform with four experiences:

1. Temple Administration
2. Devotee Experience (booking and donation hooks)
3. Trust Governance (audit trails, reporting)
4. AI Temple Copilot (heuristic Phase 1)

## Installation

1. Install Accounting, HR, Inventory, Website, Portal.
2. Install **Temple Digital Platform**.
3. Assign Temple Office, Trustee, or Temple Manager groups.

## Ecosystem

Works with AI Copilot, Workflow Builder, WhatsApp, document platform, and Invoice OCR when installed.
