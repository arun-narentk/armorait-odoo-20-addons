# Veterinary ERP Core Roadmap

## Phase 1 (current)

- Owners, pets, appointments, vaccinations, medical records, lab, surgery, grooming, boarding
- Clinic and vet dashboards
- Heuristic AI hooks

## Phase 2

- Owner mobile app: bookings, vaccination history, reminders
- Pharmacy batch and expiry tracking
- WhatsApp vaccination and appointment reminders

## Phase 3

- Livestock module extension
- Speech-to-note clinical documentation
- Multi-branch analytics and imaging integrations
