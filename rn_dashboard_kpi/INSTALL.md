# Install

1. Place `rn_dashboard_kpi` under your Odoo addons path (`armora/`).
2. Restart Odoo.
3. Update the Apps list.
4. Install **Dashboard KPI Studio**.
5. Assign **Dashboard KPI Studio / User** or **Manager**.
6. Optional: load demo data for a Welcome dashboard.
