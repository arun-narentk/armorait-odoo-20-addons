# User Guide

1. Open **Dashboard Studio** from the main menu.
2. Create a dashboard and set theme, layout, and sharing.
3. Add items (tiles, charts, lists) with a model, domain, and aggregation.
4. Add filters and bookmarks as needed.
5. Use **Open Dashboard** for the OWL client action, or **Create Menu** for a shortcut.
6. **Export** downloads a portable JSON definition.
