# Armora GSTIN Verification

Odoo **18.0** module in the Armora GST Suite.

## Purpose

GSTIN structure checks and verification workflows for Odoo 20.

- Reuse Armora GSTIN structural validation
- Store verification results and review status
- Support partner and company GSTIN checks without inventing portal claims

## Dependencies

- `armora_gst_base`

## Status


Prompt 2 boundary: see [ARCHITECTURE.md](ARCHITECTURE.md).
Installable scaffold. Domain models, workflows, and tests are implemented in follow-up steps.

## Notes

Does not claim GST Portal API access unless separately configured. Complements l10n_in_gstin_status.
