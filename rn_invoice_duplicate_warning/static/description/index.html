Prevent Duplicate Vendor Invoices

Detect duplicate vendor invoice numbers before posting. Simple, lightweight, and multi-company ready.

Overview

Invoice Duplicate Number Warning stops accounting users from accidentally posting the same supplier invoice twice. It checks Bill Reference for the same vendor and company at posting time.

Why Duplicate Vendor Invoices Are Dangerous

  • Duplicate payables and overpayment risk
  • Messy vendor reconciliation
  • Harder audit trails
  • Wasted AP time correcting posted bills

How It Works

  1. User enters a vendor bill with a Bill Reference
  2. User clicks Post
  3. Module compares company + commercial vendor + normalized reference
  4. If a draft or posted duplicate exists, a clear warning dialog opens

Duplicate Vendor Invoice Detected

Vendor: ABC Suppliers
Invoice Number: INV-2026-00125
Existing Bill: BILL/2026/00458
Status: Posted

Warning Mode and Block Mode

Warning Mode (default) Cancel, open the existing bill, or continue anyway.
Block Mode (optional) Posting is blocked until the invoice number is unique.

Multi-Company Support

Duplicates are evaluated per company. The same supplier invoice number in Company A does not warn Company B.

Key Features

  • Vendor bill Bill Reference checks
  • Commercial partner matching
  • Case-insensitive and trimmed comparison
  • Draft and posted duplicates
  • Accounting settings toggles
  • No extra menus or heavy dependencies

Simple Configuration

Accounting → Configuration → Settings → Vendor Bills → Duplicate Invoice Warning
