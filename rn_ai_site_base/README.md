# AI Business Launch Core

Turn a plain-language business description into a structured website project with pages, SEO, and Odoo publish hooks.

## Positioning

Not just an AI website builder. This is an **AI Business Launch Platform**:

1. User describes the business
2. Platform generates website structure and content
3. Companion modules add CRM, products, forms, and accounting setup
4. Publish to Odoo Website or standalone hosting

**Standalone SaaS + Odoo module** is the highest-scalability path (9.8/10). This Odoo module is the integration core (8.5/10 as add-on alone).

## Phase 1 (this module)

- Business brief capture (type, location, tone, language)
- Keyword and audience analysis from description
- Full site generation: 7 pages, content blocks, theme presets
- SEO metadata and JSON-LD structured data per page
- Publish workflow with CRM auto-lead hook (when CRM installed)
- AI credits and SaaS subscription model

## Installation

1. Add `rn_ai_site_base` to your addons path.
2. Install **AI Business Launch Core** from Apps.
3. Create a Business Brief and click **Generate Website**.
