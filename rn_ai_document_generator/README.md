# AI Document Automation

        Templates, AI drafts, approvals, and PDF output

        ## Business problem
        Teams recreate contracts, letters, and proposals manually for every customer.

        ## Solution
        AI Document Automation combines templates, placeholders, AI-assisted drafts, approval workflow, versioning, and PDF generation in Odoo.

        ## Key benefits
        - Faster document creation
- Consistent branding
- Approval before send
- Version history
- Optional OpenAI drafts
