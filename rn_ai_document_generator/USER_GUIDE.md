# User Guide

        ## AI Document Automation

        AI Document Automation combines templates, placeholders, AI-assisted drafts, approval workflow, versioning, and PDF generation in Odoo.

        ## Typical workflow
        1. Pick template
2. Fill placeholders
3. Generate AI draft
4. Approve
5. Export PDF

        ## Tips
        - Start with demo data to learn the screens.
        - Configure settings before inviting end users.
        - Use dashboards for daily operations reviews.
