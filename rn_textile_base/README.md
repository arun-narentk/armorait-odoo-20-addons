# Textile Manufacturing Core

Vertical ERP foundation for spinning mills, knitting units, dyeing plants, garment factories, and export houses on Odoo 20 Community.

## Business problem

Textile companies in Coimbatore, Tiruppur, Erode, and Karur still run production on Excel, Tally, and legacy software. Production, inventory, costing, quality, and exports rarely sit in one integrated system.

## Phase 1 (this module)

- Factory / plant master with configurable unit type
- Production departments and work centers
- Machine registry (knitting, dyeing, loom, utilities)
- Yarn specification master (count, blend, GSM, lot hooks)
- Operations dashboard with machine utilization
- SaaS subscription and AMC tracking

## Regional focus

Built for the South India textile belt with extension points for export houses and job-work networks.

## Installation

1. Add `rn_textile_base` to your addons path.
2. Install **Textile Manufacturing Core** from Apps.
3. Open **Textile > Configuration > Textile Settings**.
4. Create factory, departments, machines, and yarn specs.
