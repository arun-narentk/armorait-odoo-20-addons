# Workforce Intelligence

ARMORA IT Technologies HR intelligence suite for Odoo 20 Community.

Payroll analytics, overtime, attendance cost, attrition, compliance KPIs, and AI workforce summaries.

## Phase 1 features

- Executive payroll overview (gross, net estimate, PF, ESI, TDS)
- Department-wise cost analysis
- Overtime hours and cost tracking
- Attrition and retention metrics
- Data quality checks for incomplete HR records
- AI payroll summary insights
- OWL command center dashboard

## Installation

1. Install HR, Attendance, Time Off, and Contracts apps.
2. Install **Workforce Intelligence**.
3. Assign **HR Analyst** or **HR Intelligence Manager** groups.
