# Dental ERP Core

ARMORA IT Technologies dental clinic operating system for Odoo 20 Community.

Focused healthcare vertical for dental practices and multi-chair clinics. Smaller scope than full hospital ERP, faster to sell and implement.

## Phase 1 features

- Patient profiles: history, allergies, consent, family links
- Appointments: dentist schedule, chair allocation, check-in flow
- Dental charting: FDI tooth records (odontogram data model)
- Treatment plans with procedures, visits, costs, progress
- Procedure catalog and invoice hooks
- Lab workflow: crown, bridge, denture requests
- Patient imaging attachments (X-ray, CBCT, photos)
- Recall system for check-ups and follow-ups
- Clinic owner and dentist OWL dashboards
- AI hooks: clinical notes draft, recalls, revenue Q&A

## Why Dental before Hospital

Narrower problem, shorter sales cycles, no need for every hospital department on day one.

## Installation

1. Install Accounting, HR, Inventory, Website, Portal.
2. Install **Dental ERP Core**.
3. Assign Reception, Dentist, or Clinic Manager groups.

## Ecosystem

Works with AI Copilot, Workflow Builder, WhatsApp, document platform, and Invoice OCR when installed.
