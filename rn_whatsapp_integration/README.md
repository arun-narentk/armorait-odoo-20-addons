# WhatsApp Integration

        Share invoices, payments, and order updates via WhatsApp

        ## Business problem
        Customers miss invoice and delivery emails, slowing collections and support.

        ## Solution
        WhatsApp Integration lets staff send invoices, payment links, and shipment updates from Odoo forms in one click.

        ## Key benefits
        - Send invoices on WhatsApp
- Payment link messages
- Delivery notifications
- Reminder scheduling
- Message history in Odoo
