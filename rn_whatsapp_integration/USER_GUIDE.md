# User Guide

        ## WhatsApp Integration

        WhatsApp Integration lets staff send invoices, payment links, and shipment updates from Odoo forms in one click.

        ## Typical workflow
        1. Configure API
2. Open invoice or order
3. Send WhatsApp
4. Log message
5. Track reminders

        ## Tips
        - Start with demo data to learn the screens.
        - Configure settings before inviting end users.
        - Use dashboards for daily operations reviews.
