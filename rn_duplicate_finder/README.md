# Smart Duplicate Finder

Generic duplicate detection for any Odoo 20 model with configurable weighted rules, fuzzy matching, ignore pairs, and merge wizard.

## Highlights

- Rule-based scans on any `ir.model` record type
- Exact, fuzzy, and phone digit matching
- Scheduled auto scans
- Partner merge via native Odoo merge wizard
- Multi-company security
