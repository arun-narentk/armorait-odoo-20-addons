# Armora GST Vendor Compliance

Odoo **18.0** module in the Armora GST Suite.

## Purpose

Vendor GST compliance monitoring for Odoo 20.

- Monitor vendor GSTIN completeness and verification status
- Highlight vendors with repeated GST document issues
- Support purchase-side compliance reviews

## Dependencies

- `armora_gst_base`

## Status


Prompt 2 boundary: see [ARCHITECTURE.md](ARCHITECTURE.md).
Installable scaffold. Domain models, workflows, and tests are implemented in follow-up steps.

## Notes

Partner-centric compliance. Does not scrape GST Portal data by default.
