# Record Timeline

Visual GitHub-style timeline for sale orders, purchase orders, invoices, and CRM leads on Odoo 20 Community.

## Features

- Automatic timeline logging on create and state changes
- Timeline templates per model and transition
- Smart button and notebook widget with category filters
- PDF export and lazy loading (50 events per page)
- Multi-company security with user and manager groups
