# Smart Notes

Context-aware sticky notes for Odoo 20 Community by ARMORA IT Technologies.

## Overview

Smart Notes is a lightweight annotation layer for business records. Pin colorful reminders on sale orders, invoices, CRM leads, contacts, products, and employees without relying on chatter alone.

## Key features

- Document panel with pinned note cards
- Smart button note counter on supported forms
- Color, icon, and priority markers
- Quick templates and admin-defined presets
- User mentions with notifications
- Reminder dates that create activities
- Kanban, list, search, and visibility filters

## Installation

1. Copy `rn_smart_notes` into your addons path.
2. Update the apps list and install **Smart Notes**.
3. Assign the **Smart Notes User** group to your team.
