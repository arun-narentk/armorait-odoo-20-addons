# Attachment Preview

Preview PDFs, images, Office files, videos, audio, and text directly inside Odoo without downloading them.

## Features

- Visual thumbnail strip on attachment widgets
- Scheduled thumbnail generation for images, PDF, and Office files
- OCR search across extracted attachment text
- Office preview for DOCX, XLSX, and PPTX
- PDF annotations with page notes
- Hover preview for images and lightweight files
- Full-screen gallery viewer
- Secure preview respecting Odoo ACLs

## V2 Highlights

- **Thumbnail cron**: background jobs store `rn_preview_thumbnail` on attachments
- **OCR search**: menu action searches indexed text in PDF, text, and Office files
- **Office engine**: stdlib ZIP/XML HTML preview, no Microsoft license required
- **PDF annotations**: add, list, and delete page notes from the preview dialog
