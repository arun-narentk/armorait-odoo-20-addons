# Changelog

## 20.0.2.0.0 (2026-07-11)

- Thumbnail generation cron with stored preview thumbnails on attachments
- OCR text extraction cron and global OCR search wizard
- Office preview engine for DOCX, XLSX, and PPTX (stdlib XML, no Office license)
- PDF annotations with page notes and preview dialog sidebar
- Settings for OCR toggle and cron batch sizes
- Enhanced attachment widget with generated thumbnails and Office/PDF dialogs

## 20.0.1.0.0 (2026-07-11)

- Initial release of Attachment Preview for Odoo 20 Community
- Thumbnail strip with Preview and Download actions
- Hover preview for images and lightweight files
- Full-screen gallery viewer for PDF, image, video, audio, and text
- Sale order attachment tab and marketplace live captures
