# Hospital ERP Core

ARMORA IT Technologies foundation for clinics and small-to-mid hospitals on Odoo 20 Community.

Targets 20-200 bed hospitals, multi-specialty clinics, dental, eye, fertility, and day-care centers.

## Phase 1 features

- Patient registration with UHID, allergies, chronic conditions, family, insurance, consent
- Appointments with queue tokens, doctor schedules, walk-in support
- EMR encounters: consultation notes, diagnoses, prescriptions
- Doctor dashboard: today schedule, waiting queue, patient context
- Inpatient foundation: wards, beds, admissions, discharge
- Hospital billing lines linked to customer invoices
- AI hooks: medical scribe draft, discharge summary, allergy warnings, executive Q&A
- Hospital management dashboard

## Not in Phase 1 (roadmap)

Pharmacy dispensing, laboratory workflow, radiology, OT scheduling, insurance TPA integration, device interfaces.

## Installation

1. Install Accounting, HR, Inventory, Website, Portal.
2. Install **Hospital ERP Core**.
3. Assign Reception, Nurse, Doctor, or Hospital Manager groups.
4. Mark doctors on HR employee records (`Is Doctor`).

## Ecosystem

Works with `rn_workflow_builder`, `rn_document_platform`, WhatsApp modules, and AI Copilot when installed.
