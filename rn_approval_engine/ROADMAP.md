# Roadmap

## Phase 1 (current)

- Workflow templates, rules, sequential/parallel stages
- Delegation, history, email notify, risk hints
- PO and vendor bill hooks, dashboard

## Phase 2 (Professional)

- Visual drag-and-drop workflow builder
- Mobile approve/reject actions
- WhatsApp reminders (rn_whatsapp_connector)
- SLA escalations and reminder crons
- Expense, leave, timesheet document types

## Phase 3 (Enterprise)

- Digital signature integration
- Full workflow automation (auto PO, vendor email, payment schedule)
- AI approval summary and policy checks
- Analytics: avg approval time, bottlenecks, trends
- REST API for external approval apps
