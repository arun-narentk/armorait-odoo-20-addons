# Armora GST Exception Center

Odoo **18.0** module in the Armora GST Suite.

## Purpose

Central GST exception inbox for Odoo 20.

- Aggregate GST warnings/errors from Armora GST modules
- Assign and track exception resolution
- Provide a single accountant inbox for GST blockers

## Dependencies

- `armora_gst_base`

## Status


Prompt 2 boundary: see [ARCHITECTURE.md](ARCHITECTURE.md).
Installable scaffold. Domain models, workflows, and tests are implemented in follow-up steps.

## Notes

Foundation exception center. Downstream modules can post issues into it later.
