# Install

1. Place `rn_ai_biz_promotion` under your Odoo addons path (`armora/`).
2. Restart Odoo.
3. Update the Apps list.
4. Install **AI BIZ Promotion Landing**.
5. Optional: load demo data to get a sample GST savings promotion.
