Overview

A small Website module with a big campaign impact

Marketing teams often need a clean landing page for offers like GST savings or seasonal campaigns, but hardcoding QWeb for every launch slows everyone down.

AI BIZ Promotion Landing lets admins configure the banner, copy, benefits, and CTA in the backend. The public route /ai-biz shows the first active promotion ordered by sequence.

The Problem

  • Campaign pages are hardcoded by developers
  • Benefit cards and CTA text are hard to update
  • No clear backend place for landing content
  • Mobile layout is inconsistent across campaigns
  • Hard to keep branding aligned with AI BIZ offers

The Solution

  • Backend promotions with banner and HTML copy
  • Ordered benefit cards with icons
  • Configurable CTA button text and URL
  • Responsive Bootstrap 5 + SCSS layout
  • Public website route at /ai-biz

Key Features

Built for website managers, marketers, and Odoo admins

Hero Banner

Upload a campaign banner and show title plus subtitle in a full-width hero section.

Benefit Cards

Display benefits in a responsive 2x2 grid with icon, title, and description.

Strong CTA

Configure button text and URL for Explore AI BIZ or any campaign destination.

Drag-and-Drop Order

Reorder benefits with the sequence handle so the best offers stay first.

Active Promotion Control

Create multiple promotions. Only the first active promotion by sequence is published.

Mobile First

Cards stack to one column and the CTA becomes full width on small screens.

How It Works

1
Create a promotion
Open Website > AI BIZ Promotions and add title, copy, banner, and CTA.
2
Add benefit cards
Upload icons and write short titles and descriptions. Drag to reorder.
3
Activate the campaign
Set Active and keep the sequence lowest for the live offer.
4
Publish on /ai-biz
Visitors open the public route and see the landing page instantly.

Installation

  1. Add rn_ai_biz_promotion to your addons path
  2. Restart the Odoo service
  3. Apps → Update Apps List
  4. Search AI BIZ Promotion Landing
  5. Click Install
  6. Open Website → AI BIZ Promotions and publish content
