# AI BIZ Promotion Landing

Configurable Odoo 20 website landing page for AI BIZ promotions.

## Business Problem

Marketing teams need a fast way to publish campaign pages without hardcoding QWeb for every offer.

## Features

- Backend promotions with banner, title, subtitle, HTML copy, and CTA
- Benefit cards with icons, titles, and descriptions
- Drag-and-drop benefit ordering
- Public route `/ai-biz`
- Bootstrap 5 responsive layout with SCSS

## Installation

1. Add `armora` to addons path
2. Update Apps list
3. Install **AI BIZ Promotion Landing**
4. Open Website > AI BIZ Promotions

## Configuration

1. Create or edit a promotion
2. Upload banner and benefit icons
3. Set CTA text and URL
4. Keep the promotion Active
5. Open `/ai-biz`

Only the first active promotion (by sequence) is shown.

## Usage

- Manage content in backend
- Preview from the Website smart button
- Use demo data on a demo database for a ready GST savings page

## Permissions

- User: read promotions
- Manager: full CRUD
- Public/Portal: read published content for the website page

## Requirements

- Odoo 20 Community
- `website`, `web`, `mail`
