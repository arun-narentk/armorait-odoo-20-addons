# User Guide

        ## Resume AI Parser

        Resume AI Parser extracts skills, experience, and contact details from uploads and ranks applicants for faster shortlisting.

        ## Typical workflow
        1. Upload CV
2. Parse content
3. Map skills
4. Create applicant
5. Rank and interview

        ## Tips
        - Start with demo data to learn the screens.
        - Configure settings before inviting end users.
        - Use dashboards for daily operations reviews.
