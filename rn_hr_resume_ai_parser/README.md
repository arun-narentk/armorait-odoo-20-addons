# Resume AI Parser

        Parse CVs into skills, experience, and applicant records

        ## Business problem
        Recruiters manually retype CV data into Odoo Recruitment for every applicant.

        ## Solution
        Resume AI Parser extracts skills, experience, and contact details from uploads and ranks applicants for faster shortlisting.

        ## Key benefits
        - Save recruiter hours
- Structured applicant data
- Skill normalization
- Bulk CV upload
- AI ranking hooks
