# Domain Builder

Build Odoo search domains using plain English instead of Python-like syntax.

## Overview

ARMORA Domain Builder helps functional consultants translate business language into valid Odoo domains. It uses a dictionary-driven parser, not AI, so results stay predictable and configurable.

## Features

- Plain-English filter builder wizard
- Dictionary mappings per model
- Live domain preview and record counts
- Test, copy, save history, and favorite filters
- Supports Sales, Invoices, CRM, Products, Contacts, HR, Purchase, Stock, and Projects

## Installation

Install `rn_domain_builder` from the Odoo Apps list. Assign users to **ARMORA Domain Builder / User** or **Manager**.

## Usage

1. Open **Domain Builder > Build Filter**
2. Select a model
3. Type a phrase such as `paid invoices this month`
4. Click **Generate**, then **Test** or **Save Filter**

Managers can extend vocabulary under **Domain Builder > Dictionary**.
