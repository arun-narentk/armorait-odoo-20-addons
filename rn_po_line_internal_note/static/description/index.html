PO Line Internal Note

Record line-specific notes on Purchase Orders that stay internal.

Overview

Adds an Internal Note field on each purchase order line. Notes are for buyers only and are not printed on vendor RFQ/PO documents or shown on the vendor portal.

Key Features

  • Per-line Internal Note on the Purchase Order form
  • Optional column on the order line list
  • Not shared with vendors
  • No configuration menus
