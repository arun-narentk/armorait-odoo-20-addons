# Website Theme Framework

        40 snippets, customizer, SEO, and Bootstrap 5 theme base

        ## Business problem
        Agencies rebuild the same website snippets and theme options for every Odoo project.

        ## Solution
        Website Theme Framework is an ARMORA theme base with 40 snippets, mega menu, customizer, animations, and SEO helpers for Odoo Website.

        ## Key benefits
        - Faster website launches
- Consistent ARMORA design
- 40 ready snippets
- Live customizer
- Bootstrap 5 native
