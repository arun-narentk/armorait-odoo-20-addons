# User Guide

        ## Website Theme Framework

        Website Theme Framework is an ARMORA theme base with 40 snippets, mega menu, customizer, animations, and SEO helpers for Odoo Website.

        ## Typical workflow
        1. Install theme
2. Pick palette
3. Drop snippets
4. Customize header
5. Publish site

        ## Tips
        - Start with demo data to learn the screens.
        - Configure settings before inviting end users.
        - Use dashboards for daily operations reviews.
