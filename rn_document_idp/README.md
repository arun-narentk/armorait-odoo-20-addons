# AI Intelligent Document Processing (`rn_document_idp`)

AI Intelligent Document Processing (IDP) platform for Odoo 20 Community.

## Vision

Document gateway for your ERP:

Capture > Classify > Extract > Validate > Business Rules > Review > Odoo Transaction

## Phase 1 (current)

- Multi-channel capture (upload, email, WhatsApp, API hooks)
- Automatic document classification
- Field extraction for vendor invoices, POs, delivery challans
- Business validation with confidence scoring
- Review queue and duplicate detection
- Three-way match hooks (PO vs invoice)
- Fraud alert scoring
- Vendor bill posting
- Analytics dashboard and conversational search

## Supported document types (foundation)

Finance, procurement, logistics, HR, and legal types are modeled. Phase 1 posting focuses on vendor invoices.

## Installation

Install **AI Document Processing** from Apps (technical name: `rn_document_idp`).

Depends on: `account`, `purchase`, `mail`, `web`.
