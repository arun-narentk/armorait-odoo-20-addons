# Formula Fields

Create safe stored calculated fields for Odoo models without writing custom Python methods. Formula expressions use a restricted AST evaluator and support arithmetic, comparisons, conditional expressions, and approved numeric functions.

Install the module, open Formula Fields, then create a formula for an existing model. Managers can configure fields; users can view formulas and test expressions.
