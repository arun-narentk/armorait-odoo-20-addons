# User Guide

        ## Payroll Portal

        Payroll Portal gives employees a secure portal for payslips, leave requests, and HR documents synced with Odoo HR.

        ## Typical workflow
        1. Install portal
2. Enable employees
3. Employee logs in
4. Download payslip
5. Submit leave

        ## Tips
        - Start with demo data to learn the screens.
        - Configure settings before inviting end users.
        - Use dashboards for daily operations reviews.
