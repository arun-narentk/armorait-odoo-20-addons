# Payroll Portal

        Employee self-service for payslips, leave, and HR documents

        ## Business problem
        HR teams email payslips and answer the same leave questions repeatedly.

        ## Solution
        Payroll Portal gives employees a secure portal for payslips, leave requests, and HR documents synced with Odoo HR.

        ## Key benefits
        - Employee payslip downloads
- Leave request workflow
- HR document access
- Mobile-friendly portal
- Role-based security
