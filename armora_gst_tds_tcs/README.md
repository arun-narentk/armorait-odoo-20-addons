# Armora GST TDS/TCS

Odoo **18.0** module in the Armora GST Suite.

## Purpose

GST TDS and TCS tracking helpers for Odoo 20.

- Identify GST TDS/TCS relevant documents
- Track TDS/TCS amounts for review
- Support accountant checks around GST withholding scenarios

## Dependencies

- `armora_gst_base`

## Status


Prompt 2 boundary: see [ARCHITECTURE.md](ARCHITECTURE.md).
Installable scaffold. Domain models, workflows, and tests are implemented in follow-up steps.

## Notes

Does not replace Odoo Indian withholding modules. Complements l10n_in_withholding where installed.
