# ERP Health Analyzer

ARMORA IT Technologies commercial module for Odoo 20 Community.

## Overview

ERP Health Analyzer is an AI-assisted ERP intelligence layer for Odoo. It scans performance, security, data quality, accounting hygiene, module complexity, and upgrade risk, then turns the findings into practical recommendations.

## Business Problem

Most Odoo systems drift over time. Teams accumulate scheduled jobs, unused modules, duplicate data, permission sprawl, reconciliation backlog, and upgrade risk without clear visibility.

## Phase 1 Features

- Scan targets with reusable health scopes
- Automated scan runs with risk scoring
- Findings by category and severity
- Executive OWL dashboard for score and findings feed
- Multi-company security rules
- Demo data and automated tests

## Installation

1. Add `rn_erp_health_analyzer` to the `armora/` addons path.
2. Update apps list and install **ERP Health Analyzer**.
3. Create scan targets and run scans from the backend.

## Usage

Open **ERP Intelligence** to manage targets, scans, and findings. Use the dashboard to review recent risk and consultant-ready recommendations.
