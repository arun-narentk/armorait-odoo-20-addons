# Manufacturing Intelligence

ARMORA IT Technologies factory command center for Odoo 20 Community.

Answers operational questions: why production fell, where bottlenecks are, which orders risk delay, and how OEE is trending.

## Phase 1 features

- Executive summary KPIs (production %, delays, utilization, WIP)
- Production output (today, week, month)
- Work center live status (running, idle, breakdown, maintenance)
- OEE records (availability, performance, quality)
- Downtime logging
- Shift framework (A/B/C)
- Inventory and purchase risk KPIs
- Bottleneck detection
- AI factory summary insights
- OWL command center dashboard

## Installation

1. Install **Manufacturing** (`mrp`) and dependencies.
2. Install **Manufacturing Intelligence**.
3. Assign **Factory Viewer** or **Factory Manager** groups.

## Usage

Open **Manufacturing Intelligence > Command Center** for live KPIs.
Configure shifts, OEE targets, and settings under Configuration.
