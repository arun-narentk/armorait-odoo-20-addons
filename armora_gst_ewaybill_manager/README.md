# Armora GST E-Way Bill Manager

Odoo **18.0** module in the Armora GST Suite.

## Purpose

Manage and monitor E-Way Bill status for Odoo 20.

- Track E-Way Bill generation and validity
- Highlight pending, expired, or failed E-Way Bills
- Operational views for logistics and accounts teams

## Dependencies

- `armora_gst_base`

## Status


Prompt 2 boundary: see [ARCHITECTURE.md](ARCHITECTURE.md).
Installable scaffold. Domain models, workflows, and tests are implemented in follow-up steps.

## Notes

Complements Odoo l10n_in_edi_ewaybill and existing armora_gst_ewaybill extensions.
