# User Guide

        ## Inventory Forecast

        Inventory Forecast analyzes movement, forecasts demand, suggests reorder points, and surfaces alerts in an OWL planning dashboard.

        ## Typical workflow
        1. Sync stock moves
2. Run forecast job
3. Review ABC classes
4. Adjust reorder rules
5. Raise PO

        ## Tips
        - Start with demo data to learn the screens.
        - Configure settings before inviting end users.
        - Use dashboards for daily operations reviews.
