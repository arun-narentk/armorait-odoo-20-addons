# Armora GST Calendar

Odoo **18.0** module in the Armora GST Suite.

## Purpose

GST return and compliance calendar for Odoo 20.

- Track GST return due dates by period
- Company-specific filing calendar reminders
- Overview of upcoming GST compliance deadlines

## Dependencies

- `armora_gst_base`

## Status


Prompt 2 boundary: see [ARCHITECTURE.md](ARCHITECTURE.md).
Installable scaffold. Domain models, workflows, and tests are implemented in follow-up steps.

## Notes

Calendar helpers only. Does not file returns or connect to GST Portal.
