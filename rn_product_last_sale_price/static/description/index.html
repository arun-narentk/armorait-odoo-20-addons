Product Last Sale Price

Select customer, select product, immediately see what they last paid.

Overview

Shows the effective last confirmed sale price for the selected customer and product on every sale order line. Unit Price is never changed automatically.

Key Features

  • Latest confirmed sale price (not highest price)
  • Discount-aware effective price
  • Ignores draft and cancelled orders
  • Multi-company and multi-currency
  • UoM conversion
