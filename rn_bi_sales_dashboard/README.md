# Sales Dashboard

        Revenue KPIs, targets, charts, and sales analytics

        ## Business problem
        Managers export spreadsheets to understand revenue, pipeline, and team performance.

        ## Solution
        Sales Dashboard delivers KPI cards, filters, targets, Chart.js-ready datasets, and an OWL analytics shell for Odoo sales data.

        ## Key benefits
        - Revenue and order KPIs
- Configurable widgets
- Sales targets tracking
- Export-ready architecture
- Built for BI suite expansion
