# User Guide

        ## Sales Dashboard

        Sales Dashboard delivers KPI cards, filters, targets, Chart.js-ready datasets, and an OWL analytics shell for Odoo sales data.

        ## Typical workflow
        1. Open dashboard
2. Pick period filter
3. Review KPIs
4. Drill into targets
5. Export snapshot

        ## Tips
        - Start with demo data to learn the screens.
        - Configure settings before inviting end users.
        - Use dashboards for daily operations reviews.
