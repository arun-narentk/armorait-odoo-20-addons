# Dashboard Core

        Shared OWL dashboard shell for ARMORA analytics modules

        ## Business problem
        Every dashboard module rebuilds filters, widgets, TV mode, and KPI snapshots from scratch.

        ## Solution
        Dashboard Core is the shared foundation for ARMORA dashboards: widgets, filters, alerts, KPI snapshots, and TV-ready refresh.

        ## Key benefits
        - Reuse across ARMORA suite
- Consistent UX patterns
- Widget and filter engine
- Alert snapshots
- Manufacturing-ready base
