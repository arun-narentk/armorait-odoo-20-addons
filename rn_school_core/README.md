# AI School Operating System

ARMORA IT Technologies school platform for Odoo 20 Community.

Positioned as an **AI School OS** for private schools that want automation and parent engagement, not another basic fee/attendance ERP.

## Phase 1 features

- Student profiles, parents, medical notes, class allocation
- Admission workflow: enquiry, application, verification, interview, enrollment
- Fee structures, installments, invoice hooks, scholarships/discounts
- Attendance sessions (manual, QR-ready) with parent absence notifications
- Timetable and teacher schedules
- Exams, marks, grades, ranks, AI report card comments
- Homework assignments and submissions
- School notices and parent portal hooks
- Principal and teacher dashboards
- AI student risk detection, academic analytics Q&A, admission assistant

## Differentiation

| Generic school ERP | rn_school_core |
|------------------|----------------|
| Static forms | Workflow automation hooks |
| Manual parent comms | Notification and portal ready |
| Generic report cards | AI comment drafts |
| Reactive support | At-risk student detection |

## Installation

1. Install Accounting, HR, Website, Portal, Calendar.
2. Install **AI School Operating System**.
3. Set current academic year in School Settings.
4. Assign Staff, Teacher, or School Administrator groups.

## Ecosystem

Integrates with `rn_workflow_builder`, WhatsApp, AI Copilot, and document platform when installed.
