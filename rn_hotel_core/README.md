# Hotel ERP Core

ARMORA IT Technologies hotel platform for Odoo 20 Community.

Targets boutique hotels, resorts, homestay chains, and serviced apartments that want ERP plus front office on one stack.

## Phase 1 features

- Room types and rooms with live status
- Reservations (walk-in, corporate, group hooks)
- Front desk check-in and check-out with guest folio
- Housekeeping workflow: dirty, cleaning, inspection, available
- Folio billing linked to accounting invoices
- Room service and maintenance request foundation
- Visual room board and GM dashboard (occupancy, ADR, arrivals)
- AI hooks: dynamic pricing suggestion, concierge replies, revenue Q&A

## Entry strategy

Start with small properties (1-3 sites), not large hotel chains requiring OTA and lock integrations on day one.

## Installation

1. Install Accounting, HR, Inventory, Website, Portal, Sales.
2. Install **Hotel ERP Core**.
3. Create rooms and assign Front Office or Hotel Manager groups.

## Ecosystem

Works with `rn_workflow_builder`, WhatsApp, document platform, and AI Copilot when installed.
