# User Guide

        ## GST Reports

        GST Reports builds on l10n_in with return periods, validation issues, dashboard shell, and export-ready architecture for GSTR workflows.

        ## Typical workflow
        1. Set GST period
2. Pull transactions
3. Run validation
4. Review issues
5. Export return
6. File GST

        ## Tips
        - Start with demo data to learn the screens.
        - Configure settings before inviting end users.
        - Use dashboards for daily operations reviews.
