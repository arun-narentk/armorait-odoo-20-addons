# GST Reports

        GSTR-1, GSTR-3B, GSTR-9, and GST validation for India

        ## Business problem
        Indian businesses struggle to reconcile books with GST return formats and validation rules.

        ## Solution
        GST Reports builds on l10n_in with return periods, validation issues, dashboard shell, and export-ready architecture for GSTR workflows.

        ## Key benefits
        - India GST focused
- Return period tracking
- Validation issue log
- Accountant-friendly menus
- Multi-company security
